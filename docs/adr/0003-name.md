# ADR-0003: Name

Status: accepted (2026-10-30)

An ostler looks after travellers' horses at an inn: it readies the mount so the rider can get on with the journey. That is the role here for a coding agent. Checked 2026-10-30: `ostler` and `ostler-{cli,mcp,forms,memory,cdp,engine,dom,bench}` are unregistered on crates.io; `ostler` is unregistered on npm. Rejected: `quill` (taken on crates.io and npm, and ambiguous with Quill.js), `cairn`, `engram`, `mnemos`, `marginalia`, `palimpsest` (all taken on crates.io and npm).
