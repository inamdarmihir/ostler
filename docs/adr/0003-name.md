# ADR-0003: Name

Status: accepted (2026-10-30)

"Waymarker" is a trail marker, which is what the memory system leaves for later runs. Checked 2026-10-30: `waymarker` and `waymarker-{cli,mcp,forms,memory,cdp,engine,dom,bench}` are unregistered on crates.io; `waymarker` is unregistered on npm. Rejected: `quill` (taken on crates.io and npm, and ambiguous with Quill.js), `cairn`, `engram`, `mnemos`, `marginalia`, `palimpsest` (all taken on crates.io and npm).
