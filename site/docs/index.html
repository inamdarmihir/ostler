Ostler MCP browser documentation

Ostler is an open-source MCP browser for AI coding agents such as Claude Code, Codex and Cursor. It checks its own work: research answers cite only pages it actually read, with every quote verified, forms are filled in one call with every value read back, and Qdrant remembers what worked. It speaks MCP to coding agents and A2A to other agents.

Status: v0.2, early

Tested end to end against real Chrome and a real Qdrant server, but evaluated on local fixtures, not the open web. The docs say what was measured and what was not. Features marked Unreleased are on the main branch and not in a tagged release.
